# Changelog

## 0.1.0

Initial release.

- Language-independent color detection for files, untitled documents and custom languages.
- Native VS Code swatches and color-picker integration.
- HEX, RGB(A), HSL(A), HWB, LAB, LCH, OKLAB, OKLCH and `color()` support.
- Named CSS colors (`auto` / `always` / `never`) including `transparent`.
- Format conversion command with alpha-loss confirmation.
- Format and style preservation, minimal edits and undo/redo support.
- CSS selector and context filtering to reduce false positives.
- Settings, tests and VSIX packaging.
